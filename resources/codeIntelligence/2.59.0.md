# Code intelligence

Navigate and map a codebase. The `codeIntelligence:` resource has two families
of operations, each with its own reference page.

Works in workflow and agent mode.

| Operations | What they do | Reference |
| :--- | :--- | :--- |
| `symbolSearch`, `definition`, `references`, `hover`, `diagnostics` | Live code navigation via a language server, falling back to ripgrep | [Code navigation](https://kdeps.com/workflow/resources/code-navigation) |
| `indexFolder`, `graphFile`, `graphTopic`, `graphAll` | Build and query a persistent graph of which files link to which and share a topic | [Folder graph](https://kdeps.com/workflow/resources/code-graph) |
